Featured case study / Mobile app

Market Lens.

Version 01 / Working name

Before considering a company, I wanted to understand it. Getting that context meant jumping between too many places.

While learning about investing, I kept hearing the same advice: research a company, its financials, and what is happening around it. I built a mobile app to bring that research into one place and make it easier to follow the Nigerian market.

01 / The research flow

  • 01See the market index and browse companies listed on NGX.
  • 02Check a company’s share price and latest financial statement.
  • 03Follow company, market, and Nigerian economic news.

02 / Working with API limits

Free data sources did not cover everything I needed, so I combined tools: Tavily to search for company information and Groq to summarize selected details.

03 / Built with

React Native Supabase NGN API Tavily API Groq API
